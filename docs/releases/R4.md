## Operation и attempt state machines

`AIJob` — логическая операция; `AIAttempt` — внешняя попытка; существующий `DocumentTask(kind=AI)` — delivery obligation. Нового несовместимого outbox нет. Prompt contract `AI_PROMPT_VERSION=campusforge-study-r4-v1` входит в input hash и retained parameters; worker отвергает неподдерживаемую версию snapshot. При изменении prompts перед rollout необходимо повысить эту версию. DB unique `(workspaceId,idempotencyKey)`, `(operationId,number)`, task.operationId и FlashcardSet.operationId дополняют atomic transition fences.

| State      | Переход и durable effect                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PENDING    | Auth/member/source checks, immutable text/version/model/parameters hash, reservation и outbox сохраняются одной transaction до Redis                   |
| PROCESSING | CAS claim с token, finite lease/deadline; heartbeat продлевает только действующую claim; STARTED attempt сохраняется до transport                      |
| RETRY_WAIT | Только разрешённый известный HTTP rejection; attempt error/uncertainty сохраняются, backoff и remaining attempt/time budget проверяются                |
| COMPLETED  | Только validated output; source ACTIVE fence, singleton result/artifact, attempt SUCCEEDED, operation/outbox completion и settlement одной transaction |
| FAILED     | Nonretryable failure, исчерпание бюджета, deadline без неизвестного вызова либо потерянный output после persisted response; ledger сохраняется         |
| UNCERTAIN  | Network/timeout/abort, crash после STARTED или accounting persistence failure; automatic provider retry запрещён, резерв удерживается                  |
| CANCELLED  | Источник удалён/недоступен; publication не допускается; полученные usage/uncertainty сохраняются                                                       |

Attempt: `STARTED → RECEIVED → SUCCEEDED/FAILED`; потерянная STARTED или ambiguous transport/write даёт `UNCERTAIN`. `usageStatus=RECEIVED/MISSING/UNKNOWN/NOT_APPLICABLE` отдельно описывает наличие измерений, `estimatedCost=null` означает отсутствие оценки. 5xx не объявляется бесплатным: retry permitted policy сохраняет UNKNOWN accounting. Technical correlation/error fields settled terminal attempts позже compact; numeric ledger/identity остаются.

Queue task: `PENDING → CLAIMED(token,lease) → PENDING` после delivery; `DONE` только после operation terminal transaction. Stable job ID `ai-{operationId}`, payload только `{operationId}`. Потерянный Redis record или повторный dispatcher не создаёт независимую генерацию. Повторный key возвращает receipt без нового резерва; hash mismatch явно отклоняется. Новый key допускает сознательную генерацию в пределах политики.

## Guarantees и unavoidable uncertainty

- Один committed result на operation; завершённая redelivery не вызывает provider. Старый worker не может завершить operation после истечения/смены token. Result persistence и completion не расходятся при transaction rollback.
- Admission повторяет DB membership и document lifecycle checks. Workspace budget row lock сериализует parallel requests; source row lock сериализует admission/publication с deletion. Publication lock order согласован с admission.
- До transport существует durable attempt identity. Received usage фиксируется до JSON/schema validation и независимо от artifact transaction. Ошибка validation/result DB не удаляет оплачиваемую попытку.
- Exactly-once provider invocation **не обещается**: провайдер может выполнить запрос перед crash без сохранённого ответа. Lease не является внешним idempotency key. В таком окне сохранённый STARTED становится UNCERTAIN; нового paid call recovery не делает.
- При accounting persistence failure retained STARTED/UNCERTAIN служит сигналом recovery. Exact usage потерянного ответа нельзя восстановить без независимого provider accounting. Поздний ответ stale worker может дополнить его собственную attempt ledger, но не artifact; held reserve сохраняется до reviewed reconciliation, workspace aggregate может требовать такой сверки.
- Abort ограничивает ожидание/дальнейшую работу по возможности, не доказывает отсутствие списания или остановку удалённой обработки. Валидация schema не доказывает содержательную/фактическую правильность AI.

## Execution, pricing и budgets

SDK retries `0`, BullMQ attempts `1`; retry budget принадлежит DB lifecycle. Defaults: attempts 3, connection/time-to-headers 5 s, request 30 s, operation elapsed с admission 120 s. Lease 60 s, heartbeat lease/3. Backoff exponential, jitter 0.75–1.25, cap 30 s; Retry-After служит минимальной задержкой; если она выходит за operation deadline, retry не выполняется. 429/5xx retry разрешён; 401/403/configuration/validation/partial output terminal; network/408/timeout/abort unknown автоматически не повторяются. 5xx может скрывать оплату и удерживает reserve даже при успешном следующем результате. Repair attempt не используется.

Input ceiling default 16,000: UTF-8 byte upper bound полного system/user prompt +128 framing margin, не точный tokenizer. Silent character truncation удалён. Output 2,048 tokens и 65,536 bytes. Shape strict: extra fields reject; trimmed nonempty strings, summary 1–6 sections, 1–10 terms, cards 1–30; limits отдельных строк и total bytes проверяются. Sparse results разрешены без filler.

Pricing version `openai-standard-text-2026-10-08-v1`, стандартный text tariff USD/1M tokens:

| gpt-4o / 2024-08-06, 2024-11-20      | 2.50  | 10.00  | [model](https://developers.openai.com/api/docs/models/gpt-4o)      |

Источники сверены 2026-10-08: [pricing evidence](R4-evidence/pricing-sources.md). Lookup exact identifier, без prefix matching; 4o-2024-05-13 исключён, поскольку generic current page не подтверждает его historical tariff. Estimate использует actual returned identifier и полную input rate без cached discounts; это **не provider invoice**. Unknown requested model reject до вызова, unknown actual model ledger сохраняется, output reject/cost null. Missing usage также null, не `$0`.

USD micros integer reservation покрывает max input/output всех allowed attempts. Default workspace lifetime budget $1, operation ceiling $0.10, concurrency 2 **admitted nonterminal operations**; provider process concurrency 2 отдельно. Reserve/dedupe/outbox атомарны. Delivery не резервирует повторно. Known settled terminal освобождает reserve и добавляет полученные estimates. Unknown/missing/unpriced terminal освобождает active slot, держит весь reserve и учитывает известные estimates дополнительно (консервативный double hold). Reset/refund unknown автоматически не выполняется; оператор сверяет provider usage/request IDs/time windows и оформляет reviewed adjustment. Internal admission limit не гарантирует invoice cap.

`AI_*` перечислены в [.env.example](../../.env.example), shared runtime validation, Turbo dev/start/probe. Все числа finite с проверкой ranges и deadline ordering. Web/worker policy/model должны совпадать; API key worker-only. Public errors/logs содержат safe codes/IDs, не raw text/output/SDK causes.

## Retention и recovery runbook

Completed BullMQ history age 1 day/count 1000; failed 7 days/count 1000. Lazy auto-removal дополнена periodic minute cleanup, bounded batches default 100; active/waiting/delayed records не удаляются. PARSE history сохраняет прежнее immediate-removal поведение. Queue cleanup не удаляет DB identity/idempotence, undispatched work, attempts или user artifacts. После 90 дней settled terminal attempt request/error metadata compact, numeric ledger/identity сохраняются бессрочно. UNCERTAIN diagnostics не compact до reconciliation. User artifact retention не изменена.

Compiled worker автоматически запускает dispatcher каждые 2 s, lease recovery и minute cleanup. Для recovery запустить новый `pnpm start:worker` с согласованной runtime policy. Наблюдать overdue deadlines/leases, pending tasks, STARTED/UNCERTAIN, held budget и cleanup backlog. Never auto-retry uncertain с новым key; новый key — сознательное решение с риском повторной оплаты.

Migration `20261008120000_ai_durable_lifecycle` additive; прежние migrations не изменены. Она добавляет поля/constraints/indexes, `AIAttempt` и `AIWorkspaceBudget`; legacy PENDING/PROCESSING summary/flashcard становятся FAILED с LEGACY_UNKNOWN, без provider replay. На existing target нужен backup/rollback plan, остановка всех old writers, review legacy operations, отдельный administrative `pnpm db:deploy`, затем только новый согласованный web/worker artifact и monitoring. Миграция выполнялась исключительно на свежей disposable DB. Historical unknown usage не реконструируется и не объявляется бесплатным.
