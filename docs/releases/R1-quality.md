# R1: quality and CI

Дата проверки: 4 октября 2026 года. Этот отчёт дополняется фактическими результатами R1; старые audit evidence не изменяются.

Root `typecheck` и `lint` проверяют все пять workspace packages. Root `test` исполняет содержательные suites каждого package: environment validation, isolated Prisma schema validation, structured AI output parsers без provider calls, synthetic PDF parsing и настоящий Next App Router Server Action browser regression.

`format`/`format:check` используют явные source/config/test/release-documentation patterns. Старые audit reports, evidence/screenshots, generated clients, `.next`, `dist`, `node_modules`, caches, `.env` и сторонние файлы не входят в scope.

Browser regression создаёт `apps/web/.r1-runtime-fixture` из точных копий оригинальных `CreateTaskDialog`, `TaskForm`, UI primitives, CSS и shared sources. Вместо actual task mutation используется изолированная deferred Server Action. Fixture не добавляет route в production app, не копирует `.env`, не требует DB/Redis/S3 или provider calls.

CI workflow `.github/workflows/quality.yml`: Node из `.nvmrc`, locked pnpm install, explicit Prisma generation, все package typechecks, noninteractive ESLint, scoped format check, tests с Chromium, synthetic Turbo environment probe, root ordered build и fresh production-only release install/probe. Hosted GitHub workflow не запускался: remote/push не входят в R1.

CI actions зафиксированы immutable commit SHA актуальных publisher releases: [checkout v7.0.1](https://github.com/actions/checkout/releases/tag/v7.0.1), [setup-node v7.0.0](https://github.com/actions/setup-node/releases/tag/v7.0.0), [pnpm action-setup v6.1.0](https://github.com/pnpm/action-setup/releases/tag/v6.1.0) и [upload-artifact v7.0.1](https://github.com/actions/upload-artifact/releases/tag/v7.0.1). Official `action.yml` каждого выбранного SHA проверен read-only: execution runtime `node24`. Pnpm version берётся из `packageManager`, auto-install не включён; явный frozen install остаётся отдельным шагом.

## Необходимые source corrections

ESLint настроен неинтерактивно под обновлённый Next. Убраны действительно unused imports; empty input interface заменён эквивалентным type alias. Intentional object-rest omission transient attachment fields допускается через `ignoreRestSiblings`, а обычные unused variables остаются ошибками. React 19 diagnostics `set-state-in-effect` устранены без отключения rules: browser readiness читает согласованный server/client snapshot через `useSyncExternalStore`, начальная localStorage state корректируется условно до commit, prop-driven draft синхронизируется до render, эффекты отвечают за внешние DOM side effects. Workspace pathname приходит из `usePathname`; destination после create сохраняет прежний full-page navigation через абсолютный URL. Worker startup wrapper перешёл на ESM, compiled worker остаётся CommonJS. Источники проверяются прежним strict TypeScript; `any`, `ts-ignore` и build check skips не добавлялись.

Подход для hydration и guarded state adjustment основан на официальных [React external store docs](https://react.dev/reference/react/useSyncExternalStore) и [React state adjustment guidance](https://react.dev/learn/you-might-not-need-an-effect#adjusting-some-state-when-a-prop-changes). Прочитан `frontend-senior`, existing shadcn primitives сохранены; redesign и business changes R2–R7 не выполнялись. Generated fixture исключён из основного web TypeScript scope, чтобы exact source copies не создавали второй Next app внутри production package.

## Ограничения и незакрытые findings

- **RD-03:** работающие noninteractive lint/format/typecheck/tests и executable CI config реализованы. Hosted workflow ещё не исполнялся: Git remote/push не входят в R1.
- Original document date render использует locale-sensitive `toLocaleDateString()`. При server ru-RU / browser en-US исходник воспроизвёл hydration mismatch. Это прежнее поведение сохранено в R1; browser fixture задаёт согласованные synthetic `ru-RU`, `LANG/LC_ALL=ru_RU.UTF-8`. Несогласованная locale SSR/client требует отдельного frontend correction в следующем релизе.
- Synthetic action mock не проверяет настоящие task writes, auth sessions, DB/Redis/S3 readiness, idempotence или очередь. Original demo Assistant/document behavior и прежние FE/security/pipeline findings остаются вне R1.
- ESLint 9.39.5 оставлен как documented peer compatibility exception к `eslint-config-next` plugins; details/owner/expiry в `R1-dependencies.md`. Ошибки не подавлены.
