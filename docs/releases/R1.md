## Реализовано

- Node **24.21.0 LTS**, pnpm **10.33.0**, Next **16.3.8**, согласованные React/types **19.3.0**, NextAuth **beta.32** / adapter **2.11.3**. Exact lock и совместимые scoped overrides; без `audit --fix --force` и ручного ремонта node_modules. SHA256 lockfile: `759C3BBC5725DC0D1C9722791B41415EE4848A7B3212E3ED1631A3B49BCB73CB`. Обоснование по publisher advisories: [dependency report](R1-dependencies.md).
- Все пять packages имеют typecheck/lint/test; root агрегирует scope без `--if-present`. Неинтерактивный ESLint, установленный Tailwind formatter plugin, source-only format allowlist. CI закрепляет action SHAs, Node/pnpm и выполняет frozen install, generation/validation, typecheck, lint, format, regression tests, env probe, build и production-only release smoke. [Quality report](R1-quality.md).
- Worker и workspace libraries компилируются в CommonJS `dist` с runtime exports. Единый generated Prisma Client/native engine включён в artifact; adapter types разрешаются к нему же. Maintained PDF parser и его runtime/native assets устанавливаются из production lock graph. [Packaging report](R1-packaging.md).
- `pnpm build`: Prisma generation → dependency-ordered library builds → worker/web builds. Production Node wrappers не требуют dotenv/tsx/TypeScript/Turbo; fail-fast env validation выполняется до app import и выводит только имена переменных.
- Turbo strict `dev`/`start` передаёт `S3_*` и `OPENAI_MODEL`; build-time public env отдельно включён в cache key. Runtime secrets не нужны для clean build. Локальные dev команды сохраняют загрузку `.env` и предварительную generation/library build.
- Минимальная Next API migration: Promise params/searchParams, React 19 JSX namespace, необходимые lifecycle/unused lint corrections. Type checking и build checks не отключены; `any` / `ts-ignore` не добавлены. Удалён неиспользуемый Google font loader: фактический `font-sans` использовал системный stack, поэтому typography сохранилась, а mutable внешний fetch при build исчез.
- [README/runbook](../../README.md): install, generation, quality, build, local infrastructure, built-workspace release и production start. `pnpm db:deploy` — отдельная административная команда; она не входит в install/build/start/CI и не выполнялась.

Полный перечень source/config/test/doc изменений, включая formatting-only файлы: [R1-changed-files.md](R1-changed-files.md). Новые logs/JSON/screenshots находятся только в новых release evidence directories; прошлый audit evidence не переписывался.

Конкретные блокеры и оставшиеся ограничения:

- Docker daemon недоступен. DB/Redis/S3 provisioning, disposable migrations, auth/session/redirect acceptance и полный queue/AI flow не подтверждены. Paid AI и существующая БД в R1 не использовались.
- **braces GHSA-vfj7-8cjw-p6xm, high dev-only** остаётся без опубликованного patch. **ESLint 9.39.5 EOL** временно оставлен из-за published peer ranges Next plugins; owners — repository maintainers, пересмотр до **2026-10-31**. Подробная оценка и первоисточники в dependency report.
- NextAuth остаётся security-patched prerelease; Prisma 5.22 сохранён без major/schema migration. Нулевой prod audit не доказывает отсутствие неизвестных/бизнес-уязвимостей.
- Linux/native-library artifact и hosted CI не исполнялись. Release должен собираться для той же OS/arch и совместимых native libraries, что runtime; Windows artifact не предназначен для Linux.
- Build прошёл с неснятыми warnings: deprecated `middleware` convention; Edge import traces Next (`process.cwd`) / jose (`CompressionStream`, `DecompressionStream`); Node TS module inference в source build validator. Эти warnings не подавлены. Проверенный public middleware path работает, но полный Edge JWT/session acceptance не выполнен; его совместимость и переход на `proxy` требуют отдельной проверки перед production.
- Browser regression использует exact source components и synthetic Server Actions; production public UI probe не отправляет credentials. Прежний document `toLocaleDateString()` даёт hydration mismatch при разных SSR/browser locales; fixture согласует `ru-RU`, бизнес-поведение не исправлялось.
- PDF CPU/page/time limits, hostile-file process isolation, recovery/idempotency и все data/workflow/security findings последующих релизов остаются открытыми.

Пользовательские данные, existing DB migrations, paid AI, Git commit/push и deployment не затрагивались. Baseline и прошлое audit evidence сохранены. Полный production запуск и разрешение на production не заявляются.
